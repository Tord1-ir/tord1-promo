# کاتالوگ معرفی تردوان | TORD1

این پروژه یک صفحه معرفی فارسی و واکنش‌گرا برای هدایت بازدیدکنندگان به فروشگاه اصلی تردوان است.

## فایل‌ها
- `index.html`: صفحه کاتالوگ
- `README.md`: راهنمای انتشار

## انتشار رایگان با GitHub Pages
1. در GitHub یک مخزن جدید با نام `tord1-promo` بسازید.
2. مخزن را **Public** کنید؛ GitHub Pages برای مخزن عمومی در پلن رایگان قابل استفاده است. اگر مخزن را Private می‌خواهید، شرایط پلن حساب را بررسی کنید.
3. فایل `index.html` و این `README.md` را در ریشه مخزن بارگذاری کنید.
4. به `Settings` → `Pages` بروید.
5. در بخش `Build and deployment` گزینه `Deploy from a branch` را انتخاب کنید.
6. شاخه `main` و پوشه `/(root)` را انتخاب و `Save` کنید.
7. پس از انتشار، GitHub آدرس صفحه را در همان بخش نشان می‌دهد.

## پیش از انتشار
- لینک‌ها و شبکه‌های اجتماعی را بررسی کنید.
- قیمت یا موجودی ثابت در این صفحه درج نشده تا اطلاعات منقضی نشود.
- این کاتالوگ جایگزین فروشگاه WooCommerce نیست؛ پرداخت و سفارش فقط در سایت اصلی انجام می‌شود.
- اطلاعات ورود، کلیدهای API، `wp-config.php` یا داده‌های مشتریان را در مخزن قرار ندهید.

## نکته درباره سئو
انتشار در GitHub Pages به‌تنهایی رتبه گوگل یا فروش را تضمین نمی‌کند. از کپی انبوه محتوا و لینک‌سازی مصنوعی خودداری کنید. صفحه را با محتوای مفید و اختصاصی به‌روزرسانی کنید و آمار ورودی‌ها را در ابزارهای تحلیلی بررسی کنید.
